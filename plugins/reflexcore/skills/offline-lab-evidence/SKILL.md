---
name: offline-lab-evidence
description: Inspect ReflexCore's published evidence from owned offline game experiments and explain what the results support.
---

Use `list_lab_runs` from the configured ReflexCore MCP server. Identify the run ID and map. Keep shot requests, confirmed discharges, damage events, and the independent round result separate. A missing measurement is unknown. A truncated, cancelled, or infrastructure-failed run is not an independently confirmed match. A plant or round win alone does not demonstrate combat improvement.

For comparisons use the same compatible fixture and count every attempt. Report what the evidence cannot establish. This workflow reads published summaries and does not launch a match.
